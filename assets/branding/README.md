# PromptMeld icon provenance

The PromptMeld hand icon was generated specifically for this project on
2026-07-28, then locally simplified, background-removed, resized, and packaged
as PNG and ICO assets.

The design depicts a generic raised open hand with separated middle and ring
fingers. It does not include Star Trek wording, insignia, characters, uniforms,
or copied franchise artwork, and it is not copied from an emoji vendor's
rendering.

Source artwork: `promptmeld-icon-source.png`

Packaged assets:

- `src/promptmeld/resources/branding/promptmeld.png`
- `src/promptmeld/resources/branding/promptmeld.ico`
